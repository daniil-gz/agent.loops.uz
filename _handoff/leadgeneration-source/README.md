# Loops — leadgeneration

Опубликованный тестовый лендинг: https://loops.uz/leadgeneration/

## Управление

Канонический исходник после публикации: `_handoff/leadgeneration-source/` в репозитории `~/loops.uz`. Рабочая сборка — React + Vite, base `/leadgeneration/`. Скомпилированная статика — `leadgeneration/` в корне репозитория. Общие файлы других страниц не используются.

- `src/App.jsx`: структура и поведение страницы.
- `src/data.js`: кейсы, фильтры, список направлений.
- `src/styles.css`: типографика, адаптив, анимации.
- `public/assets/`: локальные шрифты, изображения, логотипы и рукописная стрелка.

## Локальная работа

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4187
```

Открыть `/leadgeneration/` на локальном сервере. Сборка: `npm run build`. Для публикации копировать **содержимое `dist/client/`** в `~/loops.uz/leadgeneration/`. Затем `bash scripts/deploy.sh --dry-run` из корня репозитория, проверить список файлов и запустить обычный deploy. Исходники `_handoff/` на сервер не отправляются. Шаблон сохраняет необязательную упаковку Sites, но текущий сайт обслуживает nginx на собственном VPS; Worker шаблона не используется.

## Принятые решения

- Targeteria: крупная TikTok Sans, композиция hero, декоративные вырезки, карточки, этапы работы, тёмный контактный блок, анимации. Скриншот пользователя: бумажный фон, жёлтые акценты, рукописные подписи Caveat, каталог направлений.
- Это адаптация двух источников под Loops; чужие тексты, кейсы, команда и отзывы не перенесены. Результаты кейсов взяты из существующих страниц Loops, перечень клиентов — из предоставленного пользователем референса.
- Форма готовит текст и ссылку в личный Telegram `@dani_gzv`. Пользователь отправляет сообщение самостоятельно; автоматической серверной отправки здесь нет. До нажатия ссылки данные остаются в состоянии браузера, не сохраняются в localStorage и не отправляются по сети.
- Тестовая страница имеет `noindex,follow`, отсутствует в sitemap и llms.txt. Счётчики аналитики не подключены. Для SEO-релиза отдельно утвердить контент, метаданные/SSR, индексацию и измерение заявок.
- Кнопки, фильтры, раскрытия, модальные кейсы, бриф и мобильное меню работают. Для reduced motion отключены движения и плавная прокрутка.
