ANTIGRAVITY

Google Antigravity: Революция в разработке кода с ИИ

Попробовать антигравити

Что произошло?

Google только что выпустила Antigravity — агент-ориентированную IDE (интегрированную среду разработки) нового поколения. Если коротко: это VS Code на стероидах, который думает как опытный разработчик и работает сам, пока вы занимаетесь стратегией.

Платформу встроили Gemini 3 Pro — одну из самых мощных моделей для кодирования, которая вообще существует. И вот подвох: Antigravity полностью бесплатна с щедрыми лимитами, которые обнуляются каждые 5 часов.

Почему это не просто еще один редактор кода?

Большинство ИИ-помощников — это синхронный опыт. Вы пишете код, они предлагают автодополнение. Cursor работает так, GitHub Copilot работает так. Это полезно, но это все еще вы управляете процессом.

Antigravity — это другое животное. Здесь работает асинхронная модель с агентами.

Вместо того, чтобы давать команду типа «напиши функцию логина», вы выдаете задачу вроде:

«Создай приложение для отслеживания задач с красивым UI, бэкендом на Node.js и интеграцией с базой данных»

И дальше Antigravity:

  1. Планирует архитектуру
  2. Пишет код одновременно в нескольких файлах
  3. Запускает тесты в терминале
  4. Открывает браузер и проверяет, как это работает
  5. Исправляет баги на лету, если что-то не сработало

Все это происходит одновременно. Несколько агентов работают вместе как команда junior-разработчиков, которые координируют свои действия.

Главная фишка: режим браузера

Здесь Antigravity отрывает другим всем голову.

ИИ буквально открывает браузер и начинает вести себя как реальный пользователь:

  • Кликает по кнопкам
  • Заполняет формы
  • Ждет, пока загрузятся данные
  • Проверяет, что UI выглядит правильно
  • Записывает видео всего процесса

Если находит ошибку? Агенты её видят и сразу же исправляют код. Это как иметь QA-тестера, который работает вместе с разработчиком в реальном времени.

Как это выглядит на практике:

  • Вы просите: «Создай простой To-Do список»
  • Antigravity пишет полное приложение
  • Агент открывает его в браузере
  • Кликает «Add Task», добавляет текст, отмечает как выполненное
  • Если что-то не работает, видит это и чинит код
  • Показывает вам видео того, как он все тестировал

Какие модели доступны?

Главная фишка: вы можете переключаться между моделями прямо в интерфейсе:

Модель Из кого Специализация
Gemini 3 Pro Google Лучшая для кодирования. Обрабатывает большие контексты. Лидер в Web Dev Arena.
Claude Sonnet 4.5 Anthropic Хороша для сложных рассуждений и рефакторинга.
GPT-OSS 120B OpenAI Мощная, стабильная, универсальная.

Это означает: вы не привязаны к одной модели. Если Gemini лучше справляется с бэкендом, используйте его. Для фронтенда переключитесь на Claude. Это свобода выбора.

Структура интерфейса

Antigravity построена вокруг двух основных компонентов:

1. Agent Manager — это асинхронный центр управления, где:

  • Вы выдаете задачи агентам
  • Видите, как они работают в реальном времени
  • Отслеживаете прогресс в «Inbox»
  • Можете спинить несколько параллельных работ

2. Editor — это синхронный редактор кода, где:

  • Вы работаете руками, если нужно
  • Быстро редактируете файлы
  • Просматриваете артефакты, созданные агентами
  • Быстрые переходы между Manager и Editor

Это не VS Code с боковой панелью. Это переосмысление всего процесса под асинхронную работу с ИИ.

Какие языки и фреймворки поддерживаются?

Antigravity хорошо работает с:

  • Frontend: React, Vue, Svelte, Next.js
  • Backend: Node.js, Python, Java, Go, Rust
  • Стили: Tailwind CSS, Bootstrap
  • Базы данных: PostgreSQL, MongoDB, Firebase
  • API: REST, GraphQL

Агенты могут работать с любыми фреймворками, которые понимает Gemini 3. Это практически все основные стеки.

Бесплатность — есть ли подвох?

Да, есть лимиты. Но они очень щедрые:

✅ Бесплатно:

  • Gemini 3 Pro с лимитом запросов
  • Лимиты обнуляются каждые 5 часов
  • Браузер-агент полностью включен
  • Тестирование без ограничений

⚠️ Что может быть ограничено:

  • Скорость обработки при очень интенсивном использовании
  • Время одной сессии (но это редко)

По информации из документации Google, теоретически можно использовать Antigravity практически всё время, если не пытаться заспамить систему. Лимиты обнуляются достаточно часто.

Практические примеры использования

1. Быстрый прототип для клиента

Вместо того, чтобы день писать boilerplate:

  • Вы даете задачу: «Создай лендинг для маркетингового агентства с формой контакта и блоком примеров»
  • Antigravity создает полный проект за 15 минут
  • Записывает видео того, как это выглядит
  • Вы можешь сразу показать клиенту

2. Мигрировать старый проект на новый фреймворк

  • Загружаете старый код
  • Даете задачу: «Перепиши это с Express на Fastify, сохрани логику»
  • Агенты делают работу, тестируют, показывают результат

3. Написать боты для автоматизации

  • «Создай бота, который отслеживает инвентарь в Google Sheets и отправляет алерты в Telegram»
  • Antigravity пишет интеграции, создает функции, тестирует

4. Документация кодом

  • Даете сложный кодовый урок
  • Antigravity автоматически проходит через него, как тестирует приложение
  • Проверяет, что все примеры работают

Как это сравнивается с Cursor?

Параметр Cursor Antigravity
Модель Claude/GPT Gemini 3 / Claude / GPT (выбор)
Подход Chat + autocomplete Асинхронные агенты
Браузер-тестирование Нет Да, встроено
Цена $20/мес Бесплатно
Параллельные задачи Нет Да
Видео-записи работы Нет Да

Cursor — это отличный инструмент для ежедневной работы. Хороший autocomplete, быстро, удобно.

Antigravity — это инструмент для делегирования целых проектов. Вы не пишете, вы управляете.

Как начать?

  1. Перейти на antigravity.google
  2. Установить расширение для браузера (для режима browser-agent)
  3. Выбрать модель (рекомендуем начать с Gemini 3 Pro)
  4. Выбрать языки, которые вы используете
  5. Создать первый проект и выдать задачу

Вот пример первой задачи для новичка:

«Создай приложение для отслеживания привычек. Пользователь может добавлять привычки, отмечать выполненные дни, видеть статистику на графиках. Используй React для фронтенда, создай красивый UI с Tailwind. Перед завершением, протестируй всё в браузере.»

Antigravity возьмет эту задачу, создаст полный проект, протестирует его и покажет вам видео того, как все работает.

Ограничения, о которых нужно знать

Antigravity мощная, но не идеальна:

⚠️ Ограничения:

  • Сложная логика: Для очень специфичной бизнес-логики может потребоваться ручное редактирование
  • Legacy код: Старые проекты с запутанной архитектурой могут вызвать сложности
  • Стабильность: Это еще молодой продукт, иногда бывают баги
  • Безопасность: Агенты имеют доступ к терминалу — нужно быть аккуратнее с чувствительными данными
  • Производительность: На слабых машинах может работать медленно

Когда использовать Antigravity vs Cursor?

Используйте Antigravity, когда:

  • Нужно быстро создать прототип или MVP
  • Хотите делегировать весь проект ИИ
  • Нужно тестировать код автоматически
  • Нужно создать несколько проектов параллельно
  • Бюджета нет, но время есть

Используйте Cursor, когда:

  • Вы активно разрабатываете, пишете сложный код
  • Нужен быстрый autocomplete и chat-помощник
  • Работаете в своем редакторе VS Code
  • Нужна максимальная стабильность

Главные выводы

  1. Antigravity — это не просто еще один редактор. Это переосмысление того, как ИИ должен работать в разработке.
  2. Асинхронные агенты начинают вытеснять синхронный chat-интерфейс. Это будущее.
  3. Браузер-тестирование — это не просто фишка, это необходимость. Агент видит, что не работает, и чинит.
  4. Бесплатность — главное конкурентное преимущество. Google стратегически делает эту ставку.
  5. Модель-гибкость — вы можете использовать Gemini, Claude или GPT в зависимости от задачи.

Если вы разработчик, маркетолог, который нужно быстро прототипировать, или предприниматель, который хочет создать приложение без найма программиста — Antigravity стоит серьезно рассмотреть.

Это не убийца Cursor (они разные инструменты), но это мощная альтернатива для определенных сценариев. И главное — это бесплатно прямо сейчас.
